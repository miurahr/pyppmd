Security Policy
===============

Supported Versions
------------------

Only recent version of pyppmd are currently being supported with security updates.

+---------+--------------------+
| Version | Status             |
+=========+====================+
| 1.3.x   | Maintenance        |
+---------+--------------------+
| < 1.3   | not supported      |
+---------+--------------------+

Reporting a Vulnerability
-------------------------

Please disclose vulnerabilities privately through GitHub Security Advisory.
